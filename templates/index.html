About the Project

This project uses Natural Language Processing (NLP) and a machine learning classifier to analyze news text and predict whether it resembles fake or real news in the training data.

Dataset ISOT Fake and True News
Text Processing TF-IDF Vectorization
Classification Algorithm Linear Support Vector Machine (SVM)
Test Dataset Accuracy 99.65%

The reported accuracy was measured on the project's existing test split. It does not guarantee the same performance on new or real-world news. The model's prediction is not proof that a claim is true or false. Always verify important news with reliable independent sources.
